# README illustration

`business-owner.webp` is an original AI-generated editorial illustration created for the Swedish project introduction on 2026-10-18 with the built-in image generation tool. It depicts a fictional business owner in a neutral workspace and contains no real customer or financial data. It illustrates the intended working context, not a product screenshot or evidence of an implemented feature. No external reference image or third-party logo was used.

The generated PNG was converted to WebP at quality 84 for the repository, preserving the composition and dimensions (2172 × 724 pixels). The committed image is approximately 126 KiB. The README supplies descriptive Swedish alt text; essential product information remains in text outside the image.

## Generation prompt

```text
Use case: illustration-story. Asset type: panoramic GitHub README hero for an independent open-source Fortnox MCP project aimed at Swedish small-business owners across industries. Primary request: a sophisticated editorial illustration of a small-business owner calmly reviewing receipts, invoices and business paperwork at a laptop in a welcoming, neutral contemporary workspace. Casual professional clothing, ordinary desk, small stack of documents, notebook and coffee cup, warm natural daylight through a window. The laptop has an abstract text-free conversation interface that suggests AI-assisted administration without impersonating a real application. Style: elegant hand-drawn editorial illustration, subtle paper texture, clear shapes, restrained natural colours, professional and human. Composition: around 3:1 panoramic banner, one coherent scene, person, laptop and paperwork all clearly readable at GitHub README width. Avoid industry-specific settings or uniforms, restaurants, dining tables, aprons, logos, headlines, readable text, numbers, brand marks, watermarks, robots, floating holograms and misleading finished-product screenshots. Opaque background.
```
